Hierarchical Hybrid Design

The Three-Tier Escalation Ladder

Designed from first principles to prioritize privacy and local compute. Raw frames never leave device; cloud escalation acts strictly as a redacted fallback.

TIER 1 · ZERO NETWORK

Local VLM + Ranker

Chrome Gemini Nano sub-queries the goal. SmolVLM-256M on WebGPU visually grounds the target element from raw viewport pixels, and the keyword ranker corroborates confidence.

  • 100% on-device WebGPU inference
  • Sub-second local action cycle
  • Zero external data transmission
TIER 2 · INSTANT LOCAL

Ranker-Only Fallback

If the local vision model is downloading or returns low confidence, the deterministic keyword ranker plans the action alone using the scrubbed DOM.

  • Deterministic synonym scoring
  • Viewport-priority node ranking
  • Zero GPU or network requirements
TIER 3 · REDACTED CLOUD

Zero-PII Cloud Escalation

Last resort. Destructive canvas redactor blacks out all sensitive boxes (cards, passwords, OTPs). WebSocket server returns structural actions re-hydrated locally.

  • Luhn & Verhoeff checked redaction
  • Stripped URLs (origin + path only)
  • Local ValueHydrator refuses credentials

Engineering Deep-Dive

Engineered For Zero Latency & High Fidelity

Overcoming browser execution boundaries, WebGPU memory constraints, and MV3 security policies.

Prompt API in Offscreen Doc

Chrome exposes Gemini Nano to documents, not service workers. An offscreen host bridges Prompt API calls with paired temperature: 0 and topK sampling.

Per-Graph Quantization

Embeddings stay in fp16 (or fp32) to preserve token representations, while vision encoder and decoder run in q4 for maximum WebGPU throughput.

Vendored ORT WASM

WASM binaries are vendored into the extension bundle via copy-ort.mjs, preventing MV3 CSP rejections caused by remote CDN fetches.

Re-Plan On Stall

If an action stalls on dynamic single-page apps, Gemini Nano digests the updated DOM and rewrites remaining sub-objectives on the fly.

Token Slice Decoding

Generated tokens are sliced strictly from prompt length, eliminating JSON extractor lock-ins on prompt schema examples.

Termination Safeguards

Multi-step completion validator asserts full plan satisfaction, preventing early exit on intermediate search result pages.

Developer Quickstart

Run It In Four Simple Commands

Everything you need to clone, build, and run the extension unpacked in Chrome with full WebGPU support. 

# 1. Clone the repository
git clone https://github.com/amitcodes08/privacy-vision-agent.git
cd privacy-vision-agent

# 2. Install workspace dependencies
npm install

# 3. Build extension with vendored ORT WASM
npm run dev:client

# 4. Open chrome://extensions -> Load Unpacked -> select `client/dist`
